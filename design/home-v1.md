# 雲寶家園 V1 — 2026-09-28

## 體驗範圍

從原本雲寶的狀態泡泡進入家園，一次選一個目標：小屋（5 題）、小花園（8 題）、樹蔭（12 題）。答對自然累積，完成自動解鎖，只以短泡泡提醒，不自動開啟家園。完成設施可點擊，雲寶會移動去休息、澆花或乘涼，也會在家園開啟時偶爾自行走動。

固定位置、無材料背包、無額外貨幣、無每日建設任務。離線與答錯不扣進度，全部完成後仍可互動。第一版刻意維持小規模；題數是初始設計值，尚未經長期使用驗證。

## 程式與資料

- `pet-home-model.js`：目標、進度、去重、存檔讀取。
- `pet-home.js` / `pet-home.css`：原生 dialog、家園 SVG、互動與事件接線。
- `pet.js`：狀態泡泡入口、鍵盤可及性、完工提示，開啟家園時隱藏場外雲寶並暫停自主漫遊。
- `app.js`：既有 `quiz:examDone` 事件增加 `answers: [{qid, correct}]`；沿用原判分結果。
- 獨立 localStorage key `app_pet_home`（ver 1），不修改 `app_pet` 的結構，不消耗雲朵幣。轉生不清除家園。
- 計入當下已選定的目標；同一瀏覽器的本地日曆日內，科目與題號相同僅計一次，練習與模擬考共用去重。先答錯、再答對可以計入；完成目標後不預存建材。
- 寫入成功才宣布完成；讀取失敗或未知版本不覆蓋原存檔。仍沿用此網站的本機存檔模式，沒有跨裝置同步。
